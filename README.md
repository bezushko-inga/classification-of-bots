# Avito AntiBot

## Задача

Задача заключается в бинарной классификации пользователей (`cookie_id`) на основе истории их действий на платформе.

- `target = 0` — реальный пользователь;
- `target = 1` — автоматизированный сборщик данных (бот).

Для каждого `cookie_id` необходимо предсказать `score` — вероятность принадлежности к классу ботов.

## Метрика

Основная метрика — **Precision при Recall ≥ 0.7 (P@R≥0.7)**.

Для различных порогов классификации вычисляются Precision и Recall. Итоговым значением является максимальный Precision среди порогов, для которых Recall составляет не менее 0.7.

## Структура проекта

- `solution.ipynb` — основной ноутбук с анализом данных, построением признаков, обучением и сравнением моделей;
- `metric.py` — реализация метрики соревнования;
- `requirements.txt` — зависимости проекта;
- `data/` — исходные данные;
- `submission.csv` — итоговые предсказания модели.

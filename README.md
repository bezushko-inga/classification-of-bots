# Классификация ботов (Avito AntiBot)

## Задача

Существуют внешние сервисы, которые автоматически собирают данные из объявлений Авито: отслеживают цены, составляют сводки по категориям и выгружают контакты продавцов.

Команда Антибота подготовила выборку с разметкой на основе известных источников трафика. Положительный класс представлен трафиком нескольких сервисов автоматизированного сбора данных, отрицательный — трафиком, отнесённым к человеческому. 

Твоя задача — по событиям внутри суточного окна построить модель, которая присваивает каждой cookie_id оценку от 0 до 1: чем выше значение, тем вероятнее принадлежность к положительному классу.

Target: 1 — трафик известных сервисов сбора данных; 0 — трафик, отнесённый к человеческому.

## Метрика

### Precision и Recall

Пусть $y_i$ — целевая метка куки, $s_i$ — score модели. При пороге $t$ модель отмечает как ботов все куки, для которых $s_i \geq t$.

Тогда:

$$
\mathrm{Precision}(t) =
\frac{
\sum_{i=1}^{N} y_i \cdot \mathbf{1}[s_i \geq t]
}{
\sum_{i=1}^{N} \mathbf{1}[s_i \geq t]
}
$$

$$
\mathrm{Recall}(t) =
\frac{
\sum_{i=1}^{N} y_i \cdot \mathbf{1}[s_i \geq t]
}{
\sum_{i=1}^{N} y_i
}
$$

Здесь

$$
\mathbf{1}[s_i \geq t] =
\begin{cases}
1, & s_i \geq t, \\
0, & s_i < t.
\end{cases}
$$

равна 1, если score куки не ниже порога, и 0 в остальных случаях.

**Precision** показывает долю настоящих ботов среди отмеченных моделью куки, а **Recall** — долю найденных ботов среди всех ботов в выборке.

### Итоговая метрика

$$\mathrm{P@R}_{\ge 0.7} = \max_{t:\mathrm{Recall}(t)\ge 0.7}\mathrm{Precision}(t)$$

Таким образом, метрика выбирает максимальное значение Precision среди порогов, при которых Recall составляет не менее 0.7.
